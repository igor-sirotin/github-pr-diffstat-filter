Excluded paths

The PR diffstat also shows the line counts without files that match these patterns, unless every changed file matches. One gitignore-style pattern per line; lines starting with # are ignored.

GitHub token (optional)

Without a token the GitHub API allows 60 requests per hour and only public repositories. A fine-grained token with Public repositories (read-only) access, or with Pull requests: Read-only on the private repositories you need, is enough. It is stored locally in this browser and not synced.
